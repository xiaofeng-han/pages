# Xiaofeng Han

Personal page: https://xiaofeng-han.github.io/pages/

A single static page (`index.html`, no build step) covering eight years on the Oracle Cloud Infrastructure control-plane API gateway and the roles before it.

## Links for each resume version

The page opens with every project shown, and can reorder the projects and change the summary for three focuses:

| Focus | Link |
| --- | --- |
| Show all (default) | https://xiaofeng-han.github.io/pages/ |
| Traffic and gateways | https://xiaofeng-han.github.io/pages/?focus=traffic |
| Identity and security | https://xiaofeng-han.github.io/pages/?focus=identity |

## Editing

- Project text lives in the `#work` list in `index.html`; each item's `data-lens` sets which focuses ring it, and `data-skills` connects it to the Skills section.
- The order for each focus is the `order` array in `LENSES` in the script at the bottom.
- Browser print (or "Save as PDF" on the page) produces a plain printable version.
